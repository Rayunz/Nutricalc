# ⚡ RayunCalc PRO 4.0

**RayunCalc** — это современный прогрессивный веб-калькулятор суточного рациона, КБЖУ и макронутриентов с поддержкой ИИ-сканирования еды по фото, огромной базой готовых блюд, календарём питания и полноценным личным кабинетом.

Приложение полностью адаптировано для использования на iPhone в качестве PWA-приложения (с возможностью добавления на главный экран).

---

## 🚀 Основные возможности

1. **📊 Дневник питания и Рацион:**
   - Автоматический расчет суточной нормы калорий и БЖУ по формуле Миффлина — Сан Жеора на основе параметров профиля.
   - Удобный трекер калорий, белков, жиров и углеводов с визуальными индикаторами прогресса и расчет остатка на день.
   - Выбор дат в календаре для ведения истории питания за любой день.

2. **🍲 Огромный каталог блюд (135+ позиций):**
   - Умный живой поиск по блюдам и продуктам.
   - Разделение по категориям: *Столовая, Магазины и кулинария, Выпечка, Фастфуд, Паназия и суши, ПП и спортпит, Базовые продукты*.
   - Быстрый выбор множителей порции (`0.5x`, `1x`, `1.5x`, `2x`) и автоматический пересчет граммовки.

3. **📸 AI-Фотосканер:**
   - Анализ фотографий еды и декомпозиция блюда на отдельные ингредиенты с точным расчетом граммов и КБЖУ.
   - Поддержка демо-режима и возможность подключения собственного бесплатного **Gemini API Key** для анализа реальных снимков в реальном времени.

4. **📅 Календарь питания:**
   - Помесячная сетка со статусом выполнения нормы калорий за каждый день (с процентами и цветовой индикацией).

5. **👤 Профиль и автосохранение:**
   - Настройка пола, возраста, роста, веса, уровня физической активности и цели (похудение, поддержание, набор).
   - Все данные автоматически и надежно сохраняются в памяти вашего устройства (`localStorage`).

## 🤖 Как подключить ИИ для распознавания по фото

В RayunCalc встроен режим симуляции для быстрого теста, но чтобы ИИ анализировал **абсолютно любые ваши реальные фотографии еды**, выполните следующие простые шаги:

1. Перейдите на официальный сайт **[Google AI Studio](https://aistudio.google.com/)** и войдите под своим Google-аккаунтом.
2. В левом верхнем углу нажмите кнопку **«Get API key»** (Получить ключ API).
3. Нажмите синюю кнопку **«Create API key in new project»** (Создать ключ в новом проекте) и скопируйте получившийся длинный секретный код (он начинается с `AIzaSy...`).
4. Откройте ваше приложение **RayunCalc** на телефоне или компьютере и перейдите на вкладку **«📸 AI-Фото»**.
5. Нажмите на выпадающий блок **«🔑 Настройки ИИ-модели»** и вставьте скопированный ключ в поле ввода.

Готово! После этого нейросеть начнет мгновенно распознавать любые ваши фотографии тарелок и автоматически считать их КБЖУ.

## 🛠️ Как запустить проект на GitHub Pages

1. Убедитесь, что в корне вашего репозитория находится файл **`index.html`** с кодом приложения.
2. Перейдите в **Settings** ➡️ **Pages** вашего репозитория на GitHub.
3. В поле **Branch** выберите ветку `main` (или `master`) и папку `/ (root)`, затем нажмите **Save**.
4. Через минуту откройте выданную GitHub ссылку в браузере **Safari** на iPhone, нажмите кнопку **«Поделиться»** ➡️ **«На экран "Домой"»**.
